## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * При использовании роутера Keenetic включите в его настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив со [страницы последнего релиза](https://github.com/FeelingTermite/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменение режима обхода игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно перезапустить.**  
  В скобках показывается текущее состояние — включено или выключено.
  - **`IPSet Filter`** — изменение режима обхода сервисов, перечисленных в `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках указывается состояние:
    - `none` — ни один IP не проверяется
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена выбранного активного fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В конце процедуры можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если он внезапно перестал запускаться
  - **`Run Tests`** — проверка стратегий специальной утилитой:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход). Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/FeelingTermite/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В открывшейся папке найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное в конец файла `hosts` (либо замените ранее добавленные аналогичные строки)
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/FeelingTermite/tg-ws-proxy) либо любой публичный прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Со временем отдельные стратегии могут перестать работать.**
> Стратегия способна некоторое время обходить блокировку, а затем перестать работать после её обнаружения.
> В репозитории собрано много разных стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` запустите `Run Diagnostics` и проверьте, нет ли ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP

- Переключитесь на другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/FeelingTermite/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/FeelingTermite/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска, исключив специальные символы и пробелы из пути
- Запускайте разные скрипты `general` и проверяйте доступность интернет-ресурсов. Если стратегия не подошла, закройте программу через значок замка на панели задач и выберите другую
- После нахождения рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала помогать, протестируйте остальные.
- Смотрите также [#251](https://github.com/FeelingTermite/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- Проверьте, заработало ли приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, ещё раз проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/FeelingTermite/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FeelingTermite/tg-ws-proxy)
- Либо подключитесь к бесплатному MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно активируйте `ipset any`

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/FeelingTermite/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/FeelingTermite/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` или `service.bat`
